# charm-diff  Beautiful terminal diff viewer for the [Charmbracelet](https://charm.sh) ecosystem. Produces unified and side-by-side diffs with [Lip Gloss](https://github.com/charmbracelet/lipgloss) styling.  > **[Read in Portuguese](README.pt-br.md)**  ## Features  - **Unified diff** ÔÇö classic format with `+`/`-` markers and line numbers - **Git-compatible hunks** ÔÇö hunk headers (`@@ -a,b +c,d @@`), line selection and line order are identical to `git diff -U<N>` - **Side-by-side diff** ÔÇö two-column comparison that respects the requested width - **Configurable context lines** ÔÇö show as many surrounding lines as you want (default: 3) - **Predefined styles** ÔÇö GitHub-inspired and minimal terminal themes - **Custom styles** ÔÇö build your own `DiffStyle` with any Lip Gloss style - **Linear memory** ÔÇö the diff is computed with Myers' algorithm, so files with 10,000 lines do not exhaust the memory  ## Install  ```bash go get github.com/junhinhow/charm-diff@latest ```  ## Usage  ### Unified Diff  ```go package main  import (     "fmt"      diff "github.com/junhinhow/charm-diff" )  func main() {     old := "func hello() {\n\tfmt.Println(\"hello\")\n}\n"     new := "func hello() {\n\tfmt.Println(\"hello, world!\")\n}\n"      fmt.Print(diff.UnifiedDiff(old, new)) } ```  ### Side-by-Side Diff  ```go fmt.Print(diff.SideBySideDiff(old, new, 120)) ```  ### Custom Options  ```go opts := diff.Options{     ContextLines: 5,     Style:        diff.GitHubStyle(), }  fmt.Print(diff.UnifiedDiffWithOptions(old, new, opts)) fmt.Print(diff.SideBySideDiffWithOptions(old, new, 120, opts)) ```  ### Available Styles  | Style | Description | |-------|-------------| | `TerminalStyle()` | Minimal ANSI colors (default) | | `GitHubStyle()` | Green/red backgrounds like GitHub | | `DiffStyle{...}` | Build your own with Lip Gloss styles |  ## Options  | Option | Default | Behavior | |--------|---------|----------| | `ContextLines` | `3` | Lines of context kept around each change. A negative value is normalized to `0` (no context). | | `Style` | `DefaultStyle()` | Styles used to render the diff. The zero value (`DiffStyle{}`) falls back to `DefaultStyle()` instead of silently rendering without colors. |  `Options.ContextLines` applies to the unified diff. The side-by-side view always shows the whole file and highlights the differences.  ## Git compatibility  The unified diff is byte-for-byte identical to `git diff -U<N>` with respect to hunk headers, line selection and line order:  ```console $ diff.UnifiedDiff("a\nb\nc\n", "a\nX\nc\n") @@ -1,3 +1,3 @@    1    1  a    2      -b         2 +X    3    3  c ```  - The `,1` suffix is omitted when a range has a single line, exactly like git. - A hunk that only adds lines uses the position before the insertion (`@@ -0,0 +1,2 @@`). - The engine reproduces git's xdiff (Myers' algorithm in linear space), so the alignment of the changed blocks is the same as git's.  Two differences remain: charm-diff does not emit the `\ No newline at end of file` marker, and the hunk header does not carry the function name that git may append.  ## Side-by-side width  `SideBySideDiff(old, new, width)` never renders a line wider than `width`: the two columns share the space left by the line numbers and by the ` | ` separator. Widths below the minimum viable layout (`2 * (4 + 1) + 3 + 2 = 15` columns) are raised to that minimum.  ## API Reference  ### Functions  | Function | Description | |----------|-------------| | `UnifiedDiff(old, new string) string` | Unified diff with default options | | `UnifiedDiffWithOptions(old, new string, opts Options) string` | Unified diff with custom options | | `SideBySideDiff(old, new string, width int) string` | Side-by-side diff with default options | | `SideBySideDiffWithOptions(old, new string, width int, opts Options) string` | Side-by-side diff with custom options |  ### Types  | Type | Description | |------|-------------| | `Options` | Configuration: `ContextLines int`, `Style DiffStyle` | | `DiffStyle` | Lip Gloss styles for each diff element |  ### Style Constructors  | Constructor | Description | |-------------|-------------| | `DefaultStyle()` | Returns `TerminalStyle()` | | `TerminalStyle()` | Basic ANSI colors | | `GitHubStyle()` | GitHub-like colored backgrounds |  ## License  MIT  <!-- 2026-01-19 09:00:00 -
